# 開発ガイド

## 起動と確認

リポジトリのルートでローカルサーバーを起動し、`http://localhost:8000` をブラウザで開きます。

```sh
python3 -m http.server 8000
```

HTML、CSS、JavaScript の ES モジュールを直接配信する構成で、ビルド手順はありません。変更後は次を実行してください。

```sh
npm run check
npm test
```

`check` は JavaScript の構文確認、`test` は Node.js 標準テストの実行です。CI は Node.js 22 で両方を実行します。画面や操作を変えた場合は、ブラウザでも表示、ボタン、写真の保存を確認してください。

## 構成

- `index.html`、`style.css`：画面とスタイル
- `app.js`：Canvas 描画、画面操作、描画ループ、状態の保存
- `state.js`：保存データの復元、スナップショット、部屋の状態
- `motion.js`、`lighting.js`：猫の動きと部屋の照明
- `actions.js`、`settings.js`：ドア・給餌などの操作と設定
- `capture.js`：写真の生成、保存、対応ブラウザでの共有
- `tests/`：状態、操作、描画関連のロジックと写真機能のテスト
- `assets/fonts/`：同梱フォントとライセンス表示

## 変更時の注意

保存状態と設定にはブラウザの `localStorage` を使います。保存形式を変更する際は、既存データの復元と不正なデータからの回復を確認してください。データのリセット操作も意図せず変えないでください。

写真は利用者の明示操作で生成され、共有機能はブラウザの対応状況に応じて使用されます。共有や保存が使えない場合も画面を操作できる状態にしてください。

動きや描画を変更する際は、動きを減らす設定と非表示タブでの動作を確認してください。GitHub Pages でも読み込めるよう、アセット参照は相対パスを維持してください。同梱フォントを変更する場合は `assets/fonts/README.md` と `assets/fonts/OFL.txt` の表示条件も確認してください。
