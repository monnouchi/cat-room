# ねこのへや / cat-room

一部屋、一匹。眠る・伸びる・歩く・箱に入る猫を眺める、気軽な放置Webゲームです。

**[ねこのへやを開く](https://monnouchi.github.io/cat-room/)**

## 遊び方

- 「おとをならす」で玄関のチャイム、「ごはん」で給餌機を動かせます。猫は気が向いたときに反応します。
- 音を有効にすると時計が毎正時に時報を鳴らします。「おとをけす」で止められ、非表示中や過去の時報は再生しません。
- 「しゃしん」で部屋を画像にし、「ほぞん」でダウンロード、対応ブラウザでは「おくる」で共有先を選べます。写真の自動投稿やサーバー送信はありません。
- 「でんき」で照明、設定の「ぶんをみせる」で挨拶・状態文を切り替えられます。

状態と設定はこのブラウザのlocalStorageに保存され、再訪時に留守中の様子を表示します。記録を消すと最初から遊べます。保存できない環境でも眺められます。世話の義務や放置の罰はありません。

時計は端末時刻を示し、日差しと天気は架空の簡略表現です。現実の所在地・天気・カメラは取得しません。端末の「視差効果を減らす」設定では連続的なアニメーションを抑えます。

## ローカルで遊ぶ

このフォルダで`python3 -m http.server 8000`を実行し、`http://localhost:8000`を開きます。ビルド処理は不要です。ソースの確認には`npm run check`と`npm test`を使用します。
