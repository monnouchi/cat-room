Modification: fontTools subsetting and WOFF2 conversion, primary family renaming. Copyright and license metadata are retained. One Medium weight includes the current UI, hiragana, katakana, supported Japanese punctuation and ASCII. Future unsupported characters fall back to local system fonts. The font uses `font-display: swap` and makes no third-party font requests. `coverage.json` records the resulting cmap and file checksum for verification.
